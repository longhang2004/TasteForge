# TasteForge v0.1.0 — Less slop. More taste.

TasteForge's first public MVP combines a portable Agent Skill with a deterministic local CLI. No API keys, external LLM calls, database, or cloud service are required for core operations.

## Included

- `tasteforge init`: safe project-local brief and scoring configuration.
- `tasteforge suggest`: strict validation, compatibility filtering, explainable ranking, and reproducible diverse suggestions.
- `tasteforge generate`: Design DNA, semantic CSS tokens, and design rationale with recorded context, seed, weights, and versions.
- `tasteforge audit`: parsed CSS/JSX/TSX checks that distinguish verified source evidence, heuristics, and human/rendered review items.
- A curated catalog of 20 styles, 32 font pairings, 20 palettes, fundamental principles, and contextual anti-patterns.
- A useful standalone agent skill with creation, redesign, and refinement workflows.
- Examples, ten benchmark prompts, evaluation methodology, contribution/extension guides, and MIT licensing.

## Get started

Requires Node 20.19+ and pnpm 10.13.1; Node 22/24 is recommended for development.

```bash
git clone --branch v0.1.0 https://github.com/longhang2004/TasteForge.git
cd TasteForge
pnpm install --frozen-lockfile
pnpm build
pnpm tasteforge --help
```

See the [README](https://github.com/longhang2004/TasteForge/blob/v0.1.0/README.md) for the complete four-command workflow. Edit the brief before selecting a compatible direction.

## Assets

- `tasteforge-skill-v0.1.0.zip`: the standalone skill, references, workflows, and MIT license. Extract the `tasteforge` folder into the skill location supported by your agent.
- `tasteforge-0.1.0.tgz`, `tasteforge-core-0.1.0.tgz`, and `tasteforge-knowledge-0.1.0.tgz`: built npm-format packages with licenses. All three packages are coordinated; TasteForge registry packages are not published yet. Use the source quickstart for the simplest supported setup. The repository's `pnpm pack:smoke` prepares the public dependency cache, then demonstrates offline installation with local package overrides.
- `SHA256SUMS`: integrity hashes for the downloadable package and skill assets.
- GitHub's automatic source archives contain the tagged source and require installation/build as above.

## Verification

Local verification on Ubuntu/WSL2 with Node 24 passed build, strict typechecks, lint, formatting, all **34 tests**, skill metadata validation, and local documentation-link checks. The packed CLI installed offline into an isolated project and completed init → suggest → generate → audit. The production dependency audit reported no known vulnerabilities at preparation time.

GitHub CI checks Node 20, 22, and 24. The release tag identifies the exact published source revision.

## Known limits

- The audit is static: no screenshots or rendered UI were inspected. Full cascade, dynamic styling, utility classes, component internals, and runtime interactions need separate review.
- Font files are not bundled. Language subset metadata does not certify every weight, fallback, diacritic, or target environment.
- Agent-host integration has not been certified; follow your host's skill installation instructions.
- This release does not publish packages to npm and makes no benchmark improvement claim.
- Windows-mounted WSL checkouts can have slow Node startup; tests bound worker count and subprocess/workflow timeouts.

Next priorities are real agent-integration evidence, broader project token/style analysis, tested language expansion, and independent interface evaluations.
