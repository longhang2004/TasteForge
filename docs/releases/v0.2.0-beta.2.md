# TasteForge v0.2.0-beta.2

This beta makes skill effort proportional to the task, adds explained product compositions and preserves the evidence and limits from new quality comparisons. The CLI and standalone skill remain usable independently. Npm packages remain unpublished.

## Changes

- Fast for settled corrections, Standard for clear new screens/flows, Explore for unresolved structural choices. One creator by default, reusable context and on-demand references keep small work small.
- An optional existing-Playwright checkpoint helper captures natural viewport/scroll/focus, geometry and scoped errors. Task assertions and accessibility scans remain distinct; no browser/dependency install is performed by the skill.
- Four runnable conventional/adapted composition pairs use identical facts/actions within each task: operational work, commerce decisions, editorial reading and collection exploration. Product art direction is loaded only when it resolves an actual decision.
- Cost/availability guidance checks the current selected option's validity both when displaying a cost and when submitting. A blocked invalid selection must not appear to be an available payable total.
- New held-out trials and the pinned four-skill/eight-UI comparison preserve original versions, failures, corrections, ties, reviewer disagreement and incomplete resource coverage. They do not establish a universal repository winner, human-usability improvement or end-to-end cost savings.
- Release preparation can carry the exact host-tested skill ZIP into publication after verifying its hash, full source/license contents and absence of extra/duplicate members.

## Versions and compatibility

The workspace and all three packages are `0.2.0-beta.2`. The DNA schema remains `1.0`; validated generator engine/knowledge remain `0.1.0` and the external reference catalog remains `2026.11.01.2`. Existing valid DNA needs no migration. This release does not change generator scoring or token contracts.

The runtime minimum remains Node 20.19+. The configured compatibility matrix covers Node 20/22/24/26; use a maintained runtime for normal development. `VALIDATION.json` records the exact candidate commit, runtimes and actual checks. Host discovery/invocation observations are scoped to their recorded version/platform; they do not certify every agent host.

The candidate standalone ZIP completed one explicit repo-scope invocation on native Windows Codex CLI `0.166.0-alpha.5.1`, with terminal commands through Ubuntu WSL2. A separate browser follow-up passed 51 assertions and 19 natural state captures. [Host setup, raw evidence and limits](../host-integration.md) preserve the precise scope and the pre-model startup failure.

## Download and use

- `tasteforge-skill-v0.2.0-beta.2.zip`: standalone skill, references, workflows, optional helper and MIT license. Extract the `tasteforge` directory into your host's documented skill location.
- `tasteforge-0.2.0-beta.2.tgz`, `tasteforge-core-0.2.0-beta.2.tgz`, `tasteforge-knowledge-0.2.0-beta.2.tgz`: coordinated built package archives. Local archive overrides are used by package smoke tests; unpublished npm names are not claimed to resolve from a public registry.
- `TasteForge-v0.2.0-beta.2-source.zip`: exact tagged source, examples and historical/fresh evidence. Evaluation-only fonts retain OFL notices; imported skill/reference bundles retain their own MIT/Apache notices. They are not CLI/standalone-skill dependencies.
- `RELEASE_NOTES.md`, `VALIDATION.json`, `release-manifest.json`, `SHA256SUMS`: supported scope, verification coverage, file provenance and integrity hashes.

Build from the source checkout/archive for the complete CLI setup. Runtime CLI operations remain local; initial dependency installation can access the registry.

## Evidence and remaining limits

The four-skill comparison has 276 scoped task assertions, 128 natural state captures and two independently frozen AI reviews. Both reviewers favor TasteForge and constrained Impeccable composition locally, while product-direction ties and disagreements remain. TasteForge's original Field Fold output still records an invalid-stock displayed-total defect despite correctly blocking submission. That assessed artifact is unchanged; the beta hardening follow-up is separate.

Native Impeccable in that study used an offline degraded path and explicit single-creator/code-first overrides, so full native orchestration/online efficacy is unassessed. Complete provider/token/cache/billing/operator resource totals are unavailable. Manual/human usability tests remain deferred. Passing source, browser or axe checks does not establish full accessibility, comprehension or unique identity. Broader LON-95 host coverage, LON-99 diversity and LON-109 replication remain separate.
