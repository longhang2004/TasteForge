# Standalone skill installation evidence

The standalone ZIP contains the complete `tasteforge` skill folder, its references/workflows, the optional checkpoint helper and MIT license. It does not require the TasteForge CLI. Use a host's documented skill location and preserve the folder contents.

For Codex repository scope, extract that folder under a disposable project's `.agents/skills/`, then explicitly request `$tasteforge` from that project. Repository discovery locations and explicit invocation are documented in [official OpenAI documentation](https://learn.chatgpt.com/docs/build-skills). [Non-interactive mode](https://learn.chatgpt.com/docs/non-interactive-mode) documents JSONL evidence and automation permissions; use flags supported by your installed version.
