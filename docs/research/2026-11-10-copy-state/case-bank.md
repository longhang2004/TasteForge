# Contextual copy/state case bank

Date: 2026-11-10. Revision: 1. Status: curated and checked for use as review questions; product outcomes remain unmeasured. Sources: [ledger S01–S10](source-ledger.md). Related [retrospective observations](retrospective.md) identify actual retained artifacts separately.

## How to use this bank

These twelve cases are **authored illustrations**, including their imagined screen wording. They apply questions from the named sources; the screens were not observed in those threads. There is no new primary-source inspection, representative dataset, measured task effect or AI-authorship label here. AGY supplied a secondary curation draft; the integrating agent corrected attribution and unsupported specifics before this version.

Select a relevant case, inspect the actual target and decide keep/adapt/remove/unassessed. A hypothetical loss or false statement is not an observed product defect. Upgrade a contextual signal to a defect only when the applicable behavior/fact/access failure is demonstrated. A legitimate conventional pattern is an expected result, not a loophole. Cases span Decide/Work/Read/Explore and public product, import, operations, reading and collection contexts.

Every possible consequence below is a **hypothesis**, not a measured user result. Rechecks are proposed actions, not checks already executed.

## CS01 — Copy that omits the current task

- **Context/lens:** Work; a local import form's entry state.
- **Provenance:** Authored illustration informed by S01's criticism of interchangeable copy; S01 did not document this import form.
- **Class:** Contextual signal.
- **Signal:** “Your work, elevated” replaces an understandable import action and any known file conditions.
- **Possible consequence:** The visitor may not know what can be selected or what happens next.
- **Legitimate counterexample:** A campaign headline can express a brand when nearby concrete copy answers the product/action question. Ordinary cards and system fonts can remain.
- **Decision:** Adapt only the missing information. “Import a CSV file” is appropriate only if that is the real supported action; use actual implementation limits, never invented caps or encodings.
- **Recheck/limit:** Inspect supported types/conditions and the action result. Brand-name substitution is a question to investigate, not an automatic failure.

## CS02 — First-use empty state loses orientation

- **Context/lens:** Work; an operations collection with no records yet.
- **Provenance:** Authored illustration informed by S01's secondary-state anecdote and S05's preservation approach.
- **Class:** Contextual signal.
- **Signal:** A replacement illustration and “Nothing here” remove the record terminology and the available create/import action.
- **Possible consequence:** The operator may lose the expected data relationship and next step.
- **Legitimate counterexample:** A quiet first-use illustration with the real create action can be helpful. An empty table need not retain every column or match the populated geometry.
- **Decision:** Adapt the explanation/action while retaining meaningful landmarks and product nouns.
- **Recheck/limit:** Confirm this is true first use rather than filtering or failed loading; inspect the actual creation route. No mascot-size quota or measured confusion claim.

## CS03 — Validation discards valid work

- **Context/lens:** Work; a multi-field editor after invalid submission.
- **Provenance:** Authored illustration informed by S01/S05 and spec 11's retention contract.
- **Class:** Contextual signal; a defect only if unintended loss is demonstrated.
- **Signal:** The error replaces the form and clears otherwise valid entries.
- **Possible consequence:** Re-entry and an unclear recovery path may follow.
- **Legitimate counterexample:** Resetting after an explicit clear action or a successful completed workflow can be correct. No rule says every transient field must persist forever.
- **Decision:** Adapt unintended loss; preserve values, field meaning and appropriate error association within the actual persistence/security contract.
- **Recheck/limit:** Trigger the real validation case, inspect retained values, error meaning, focus and recovery. Do not claim a particular WCAG failure from a fictional source description or force focus movement for every error.

## CS04 — Specific-looking credibility without evidence

- **Context/lens:** Decide; a public product page's claim or comparison section.
- **Provenance:** Authored illustration from spec 10 C04 and product-truth constraints; not a measured S01–S10 occurrence.
- **Class:** Contextual signal; verified false claims are defects.
- **Signal:** An invented customer count or success rate fills a decorative metric slot.
- **Possible consequence:** The visitor could make a decision from unsupported evidence.
- **Legitimate counterexample:** A real approved metric with definition/period/source, or an explicitly fictional teaching fixture, can be useful.
- **Decision:** Adapt by using verified facts or an explicit authoring gap. Do not invent an SLA as a replacement or delete an owner-supplied required fact merely because verification is outside this task.
- **Recheck/limit:** Trace actual numbers and promises to the brief/source and intended scope. Source absence means unknown until resolved, not proof the real business claim is false.

## CS05 — Repetition hides a content relationship

- **Context/lens:** Decide; a plan/option comparison with shared attributes.
- **Provenance:** Authored illustration informed by S02/S06; neither source establishes task-error rates for this screen.
- **Class:** Contextual signal.
- **Signal:** Identical feature tiles scatter the attributes a visitor needs to compare.
- **Possible consequence:** Aligned comparison may become harder.
- **Legitimate counterexample:** Cards suit independent choices and compact summaries; a familiar three-card section can be entirely appropriate.
- **Decision:** Keep when the relationship is clear; adapt alignment/grouping when an actual comparison is obscured. A table is an option, not a mandatory anti-slop replacement.
- **Recheck/limit:** Compare the actual required facts at relevant widths, including selected price/conditions where implemented. Frequency of card mentions supplies no effect size.

## CS06 — Editorial styling becomes another default

- **Context/lens:** Read versus Work; reading an evidence article or repeatedly editing dense records.
- **Provenance:** Authored illustration informed by S03/S06 and S10's README-only typography example.
- **Class:** Contextual signal.
- **Signal:** Paper/serif/caption styling is applied without a task or content reason.
- **Possible consequence:** Emphasis and density may stop matching the working context.
- **Legitimate counterexample:** A long-form archive, print-work record or established editorial brand can justify those same ingredients. A neutral single-family work surface is equally legitimate.
- **Decision:** Keep a supported treatment; adapt roles/density only for a named content or access issue.
- **Recheck/limit:** Inspect the actual text, artifact and constraints. Do not infer task speed, require monospace for every technical label, or claim Kami's uninspected implementation behavior.

## CS07 — Feedback interrupts a repeated action

- **Context/lens:** Work; toggling a reversible setting or receiving an asynchronous result.
- **Provenance:** Authored illustration informed by S09's status-message explanation.
- **Class:** Contextual signal.
- **Signal:** Repeated overlay messages obscure controls despite a clear immediate control state.
- **Possible consequence:** The operator may face distraction or occlusion.
- **Legitimate counterexample:** A consequential asynchronous or cross-page result may need persistent visible feedback and appropriate announcement.
- **Decision:** Adapt feedback to the actual action; retain necessary status information. Neither universal toasts nor universal toast removal follows.
- **Recheck/limit:** Inspect visible state, programmatic control/status exposure, focus and reachability. S09 explains requirements; it did not measure annoyance here.

## CS08 — Geometry passes while content disappears

- **Context/lens:** Read; required text at the product's narrow supported width.
- **Provenance:** Authored illustration and inference from S08; S05's root clipping is a house-style choice, not evidence of a failure.
- **Class:** Contextual signal; a defect when applicable information/function loss is actually shown.
- **Signal:** Clipping or truncation conceals a required label, fact or action to make a no-overflow assertion pass.
- **Possible consequence:** Information can become unavailable despite clean geometry.
- **Legitimate counterexample:** Intentional cropping of decoration or an inherently two-dimensional region can be valid when applicable content/access requirements are met.
- **Decision:** Adapt the cause when required access is lost; keep justified clipping where it does not remove necessary information/function.
- **Recheck/limit:** Inspect rendered visibility/reachability and applicable reflow exceptions. A single screenshot cannot establish every zoom, scroll or keyboard condition.

## CS09 — A label repeats without adding meaning

- **Context/lens:** Read; headings within a long document.
- **Provenance:** Authored illustration informed by S01's eyebrow criticism and S02's contextual disagreement.
- **Class:** Craft note unless a more substantial consequence is demonstrated.
- **Signal:** A decorative label merely repeats the adjacent heading.
- **Possible consequence:** The extra element may consume attention without improving orientation.
- **Legitimate counterexample:** A category, record ID, lifecycle state or useful parent label supplies distinct meaning.
- **Decision:** Keep meaningful labels; adapt redundant ones if a small correction is worthwhile.
- **Recheck/limit:** Read the label/heading relationship in context. No uppercase, tracking, eyebrow or word-count ban; no automatic screen-reader harm claim.

## CS10 — Novelty replaces a useful familiar control

- **Context/lens:** Explore; filtering or comparing collection records.
- **Provenance:** Authored illustration from spec 10 C10, informed by S04's skepticism of vague novelty claims.
- **Class:** Contextual signal.
- **Signal:** An unfamiliar gesture replaces clear selection controls without a demonstrated need.
- **Possible consequence:** The action may become harder to discover or access.
- **Legitimate counterexample:** Spatial manipulation can be the actual task in a creative canvas; conventional checkboxes, lists and cards can be the right answer in a catalog.
- **Decision:** Keep the familiar control by default when it serves the task; adapt a novel interaction only after inspecting its purpose and access.
- **Recheck/limit:** Inspect equivalent keyboard/pointer operation and state meaning. Novelty alone establishes neither harm nor benefit.

## CS11 — Filter mismatch or local state is overstated

- **Context/lens:** Explore/Work; zero search results, a retry or a local-only success.
- **Provenance:** Authored illustration from spec 11's truthful-state examples, informed by S01.
- **Class:** Contextual signal; contradictory factual claims are defects when verified.
- **Signal:** “No records exist” is shown for active filters, or “Saved to your account” describes an in-memory result.
- **Possible consequence:** The visitor may misunderstand collection scope or persistence.
- **Legitimate counterexample:** A genuinely empty collection or confirmed account save can justify direct wording. A visibly local demo can accurately state its narrower result.
- **Decision:** Adapt to the actual state and lifetime; preserve filters/values and available reset/retry actions.
- **Recheck/limit:** Inspect actual data/filter/persistence code and behavior. Do not invent a backend or assume browser storage from the word “saved”.

## CS12 — Locale or required detail is sacrificed to fit

- **Context/lens:** Work; Vietnamese labels and mixed-language record titles at a narrow width.
- **Provenance:** Authored illustration from spec 11's language constraints and S08's information-retention question.
- **Class:** Contextual signal; demonstrated required-content loss may be a defect.
- **Signal:** Diacritics, units or necessary qualifiers are removed to make a label shorter.
- **Possible consequence:** Meaning or identity can change.
- **Legitimate counterexample:** An approved concise localized label can work when its meaning and relevant details remain available. Existing fonts can remain when actual script coverage is adequate.
- **Decision:** Adapt wrapping/hierarchy or use approved wording; preserve the language and facts.
- **Recheck/limit:** Inspect actual rendered text, glyphs, loading/fallback and reachable actions within the supported delivery contract. Visible sample diacritics do not prove full language coverage or native-speaker comprehension.

## Adoption boundary

This bank supports targeted review, not a mandatory twelve-case checklist. The packaged [copy/state reference](../../../skills/tasteforge/references/copy-and-state-coherence.md) distills the relevant decisions; it does not require reading this research folder. Existing artifacts in the retrospective are a selected two-family sample. They do not validate every illustration or show that the new guidance improves fresh generations.
