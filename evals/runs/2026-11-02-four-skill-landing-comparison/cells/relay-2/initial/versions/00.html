Before you begin

A few practical details.

Can I use my existing Markdown notes?

Yes. The supplied workflow starts with pasting Markdown change notes, then arranging sections and preparing an email draft. This landing page shows static examples; it does not implement the editor.

Does the demo connect to Git or send email?

No. There is no live Git integration or actual email sending in this slice. The local form simulates workspace setup only.

What is included for my team?

Both Monthly and Annual cover one workspace with up to 3 editors. Monthly is USD 12 per workspace each month. Annual is USD 120 per workspace billed once yearly.

What happens after the trial? Can I cancel?

The fictional offer includes a 14-day trial. This demo starts no real trial, subscription or billing agreement. A real cancellation or refund policy beyond this demo has not been supplied.

Demo privacy

Entered values stay in current-page memory. This prototype does not transmit form data, create an account, process payment or send email. There is no reload persistence, analytics or cookie use.

Demo terms

Fictional product, workspace offer and change records; local simulation only. No real trial, account, subscription, payment or email is created. Canal Docs records and contributor credits are fictional examples, not customer testimonials or real Relay Notes release history.
