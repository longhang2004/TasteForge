BEFORE YOU BEGIN

A few practical answers.

Can I use my existing Markdown notes?

Yes. The supplied workflow is to paste Markdown change notes, arrange the sections and prepare an email draft. The illustrations show fictional Canal Docs records, not an interactive editor.

Does this connect to my Git repository?

No live Git integration is implemented or promised in this slice. The local demo only simulates workspace setup.

Will it send a release email?

No. The workflow prepares an email draft. No actual sending is implemented and no email is sent by this demo.

How many editors are included?

Both plans cover up to 3 editors per workspace. Monthly is USD 12 per workspace each month. Annual is USD 120 per workspace, billed once yearly.

What happens to the 14 day trial?

The fictional offer includes a 14 day trial. This demo asks for no card and does not start a real trial, account or billing agreement.

What is the cancellation or refund policy?

No real cancellation or refund policy beyond this demo is supplied. No real subscription, payment or cancellation is processed here.
