## Provenance and rights

- Fixture/prompts and four SVG artifacts are original agent-authored comparison inputs under the repository MIT license; its original notice is copied to `common/assets/LICENSE`. No external imagery, existing brand identity, customer material or third-party UI code is copied. SVG XML parsing and font signatures are checked during setup; visual layout of later landing pages is separate evidence.
- Optional local font families: Manrope, Poppins, DM Sans, Fraunces, IBM Plex Mono. Files come from a pinned official `google/fonts` revision, with asset-specific original `OFL.txt` files beside each family. `common/fonts.css` only declares `@font-face`; it selects no font for a page. System fonts remain available. No browser font CDN, runtime network request, package install or global setting is needed.
- `common/setup-report.json` records the exact font revision/paths/URLs/hashes, setup clock coverage, unavailable files and raw download failures. A missing asset is recorded rather than silently substituted. `asset-manifest.json` freezes all owned prompt/brief/common bytes before creators start, excluding the manifest itself.
- The first observed setup clock follows an initial WSL command; exact dispatch/start and provider tokens/cost are unknown. Setup elapsed is an observed preparation segment, not creator tokens or end-to-end savings.

No human-made/source-authenticity claim, usability finding or universal ranking is inferred from these authored fixtures. Common assets support meaningful product decisions while each skill retains its own visual/workflow choices within the same task contract.
