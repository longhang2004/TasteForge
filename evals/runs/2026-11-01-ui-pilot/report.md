# TasteForge UI pilot results — 1 November 2026

Eight unmodified UIs were generated by fresh subagents: two requested model IDs × two product prompts × without/with TasteForge. Both conditions received the same product task, fixture, starter, behavior contract, and self-review allowance. The treatment additionally used the frozen skill and local CLI. See the [protocol](protocol.md) and [manifest](manifest.json).

## What this pilot observed

- All eight implementations completed the required primary-task checks at both tested viewport sizes. The pilot did not show a difference in basic task-flow completion.
- Initial-screen axe checks reported color-contrast findings in **3 of 4 baseline cases** and **0 of 4 assisted cases**. The same contrast issue also appeared in tested later states of those baseline cases. This is evidence about these implementations and states, not proof of complete accessibility or a general skill effect.
- The two anonymous AI reviews rated the assisted UI higher on information hierarchy in each of the four pairs. Several other dimensions were unchanged. The gpt-6.1-sol product-page baseline was already rated strongly.
- The Luna-assisted transfer received a lower layout/responsiveness rating than its matched baseline; reviewers noted mobile headline spacing and inconsistent result styling. These issues remained despite passing functional checks and having no axe findings.
- Both Luna product pages displayed USD 136 for two pieces and USD 8 shipping separately rather than an explicit USD 144 order total. That optional diagnostic differed by model in these examples, not by skill condition.

The practical signal is promising for palette/contrast discipline and hierarchy in this sample, with remaining workflow and responsive-design weaknesses. The results do **not** establish that TasteForge always makes a better interface. There is no aggregate taste score, effect-size estimate, significance test, or improvement percentage.

## Skill adherence and workflow friction

- All four assisted cases retained generated brief/config/DNA/tokens/guidance and loaded the generated token file. Three directly referenced `--tf-*` CSS variables; c04 copied palette values into its own CSS variables instead. Loading a token file alone does not establish coherent application.
- c02 encountered no compatible font pair for system-only delivery with English/Vietnamese coverage. It changed the brief language list to English and disclosed that Vietnamese fallback coverage was unverified. The visible Vietnamese name was rendered in the screenshots, but glyph coverage across target platforms was not certified. Treat this as workflow friction and an unverified requirement, not an access requirement successfully solved by changing the brief.
- c04 chose Learning Studio for the transfer context, while c02 chose Modern Institutional. Both commerce treatments chose Swiss Editorial. These are agent choices, not prescribed answers from the operator.
- The c04 and c08 source audits produced 53 and 71 heuristic warnings respectively, with zero source-audit errors. Warnings were retained, not all turned into mandatory fixes or used as a cross-condition quality score.
- c06 reported an empty source-audit output and saved that limitation. The operator later reran the same source audit successfully and saved it separately in `evidence/c06/operator-source-audit-recheck.json`; the creator's original record was not replaced.

## Limits and next evaluation

- One generation per condition in each pair; only two prompts.
- Model sampling seeds, token usage, backend snapshots, and inference settings are not exposed.
- Tool/bootstrap interventions are disclosed; eight-minute budget was an aim, not an enforced compute limit.
- Isolation was instructed through fresh no-history agents, not enforced by an OS sandbox separating case read access.
- Two AI reviewers in fresh contexts, not independent human users; correlated model judgments are possible.
- Creators did not receive rendered feedback. Operator inspected outputs only after submission and did not repair them.
- Task-state captures follow browser action/scroll behavior; initial top/full-page screenshots share the capture policy.
- Static/browser checks cover the saved states only; no full screen-reader, zoom/reflow, target-size, or accessibility certification.
- The treatment bundles skill instructions, references, CLI, and generated guidance; this pilot does not isolate their individual contributions.

A larger evaluation should repeat each pair at least three times, expand task categories, randomize generation order across repetitions, allow the same rendered-feedback tools to both conditions, and involve independent human reviewers. Test font delivery/coverage friction and the specificity/noise of audit warnings separately. Preserve failure cases and report each rubric dimension rather than choosing only attractive screenshots.

## Reproduction and integrity

The [manifest](manifest.json) records requested model IDs, source revision, versions, input hashes, skill hashes, case mapping, screenshot packet order, and submitted-source hashes. Full provider transcripts, backend model snapshots, model generation seeds, token counts, and compute costs are not exposed and are not fabricated. Case isolation is an instruction boundary in a shared workspace.

The UIs use plain HTML/CSS/JS and local original SVG illustrations. Serve the run folder with Python to inspect them. Browser tooling is isolated in `tools/`; replicating a browser capture requires its pinned Playwright/axe dependencies and matching browser. Copy to a new run directory before regenerating evidence; do not overwrite the preserved pilot and then claim it is the original run.

The first capture harness made two transfer-state assumptions that were corrected uniformly; its summary and the correction are retained in [harness-first-pass.json](evidence/harness-first-pass.json) and the protocol. No submitted implementation was repaired by the operator. Raw case files and the frozen skill snapshot are excluded from root auto-format/lint so later maintenance does not silently rewrite experimental evidence.
