# tasteforge

Less slop. More taste. A local, deterministic design-intelligence CLI for coding agents.

Provides `tasteforge init`, `suggest`, `generate`, and `audit`. Version 0.2 beta adds `catalog` and `inspire` for 642 attributed offline references, task-matched structural observations and baseline review gates. Imported reference IDs are not token-generating direction IDs. Requires Node 20.19+. No API key or cloud service is needed. Includes the TasteForge Agent Skill in `skills/tasteforge`. Fonts are recommended, not bundled. Static audits do not inspect a rendered UI or establish accessibility conformance.

This is the coordinated 0.2.0-beta.1 preview; see the repository README for source installation, configuration, limitations, and examples. Original code and prose are MIT licensed.
