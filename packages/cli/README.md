# tasteforge

Less slop. More taste. A local, deterministic design-intelligence CLI for coding agents.

Provides `tasteforge init`, `suggest`, `generate`, and `audit`. Requires Node 20.19+. No API key or cloud service is needed. Includes the TasteForge Agent Skill in `skills/tasteforge`. Fonts are recommended, not bundled. Static audits do not inspect a rendered UI or establish accessibility conformance.

This is a coordinated 0.1.0 MVP; see the repository README for source installation, configuration, limitations, and examples. Original code and prose are MIT licensed.
