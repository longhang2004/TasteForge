# @tasteforge/knowledge

Versioned JSON design knowledge and Zod schemas for TasteForge: 20 styles, 32 font pairs, 20 palettes, principles, and contextual anti-patterns. The exported catalog validates unique IDs and compatibility references.

The separate `@tasteforge/knowledge/references` export contains an offline, attributed catalog of 642 records from 18 pinned sources: 172 style documents/rows, 357 contextual rules and 113 template/structure records. Imported references are untrusted source observations, not validated generator profiles. Full upstream MIT notices are included in the data and `third-party/`; `reference-lock.json` binds inputs to hashes.

Font entries record upstream subset evidence and fallback limitations. Font files, brand assets and template executables are not bundled. Rankings and compatibility are editorial judgments, not scientifically validated aesthetic scores. See the TasteForge repository extension and reference-catalog guides. Original data and code are MIT licensed; attributed source text retains its upstream notices.
