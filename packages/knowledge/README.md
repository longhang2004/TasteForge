# @tasteforge/knowledge

Versioned JSON design knowledge and Zod schemas for TasteForge: 20 styles, 32 font pairs, 20 palettes, principles, and contextual anti-patterns. The exported catalog validates unique IDs and compatibility references.

Font entries record upstream subset evidence and fallback limitations. No fonts or third-party prose are bundled. Rankings and compatibility are curated editorial judgments, not scientifically validated aesthetic scores. See the TasteForge repository extension guide. Original data and code are MIT licensed.
