# @tasteforge/core

Pure deterministic context validation, hard filtering, ranking, seeded sampling, Design DNA generation, semantic tokens, and static UI audit functions. Node 20.19+, ESM, no filesystem or network operations.

The root export includes all APIs; `@tasteforge/core/engine` omits the heavier audit parsers, and `@tasteforge/core/audit` exposes static source checks. See the TasteForge repository for schemas and examples. Original code is MIT licensed.
